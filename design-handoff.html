(03)

Visual system

Everything on the site comes from these colors and three typefaces. They're set once at the top of site/styles.css. Change a value there and it changes everywhere.

Path to Glory
Archivo, weight 900Headlines and names. Uppercase, tracking −5%, line height 0.86. Variable width axis available (62–125).
(04) Pre-season mentor event:
IBM Plex Mono, 500–600Labels, file numbers, tabs and buttons. Uppercase, tracking 10–16%, 10–13 px.
Learn from the best players
Courier Prime, 700Anything "filled in by hand": form answers, the goals card, appointment cards, rosters.

Everything is a physical object. Paper sheets, a kraft folder, ID badges on lanyards, tickets, index cards, stamps and red tape. Nothing is a floating rounded box.

Objects sit slightly crooked. Rotations stay between 0.5° and 4°, alternating direction between neighbors.

Red is for tape, stamps and the one action that matters. Green only appears on team tags and confirmed states.

Paper has grain. A light noise texture is laid over paper, kraft and the desk. It's generated in CSS, so it needs no image files.

Shadows are deep and soft, like paper lifted off a dark desk. Use the --lift shadow instead of making new ones.

Brackets and numbers mean something. [Brackets] mark placeholder text, and (01)–(09) are the page numbers of the file.

(05)

Files

The project lives in the site folder. It's plain HTML, CSS and JavaScript with no build step: edit a file, refresh the page, and see the change. Every file is yours to change. Every change is saved in the GitHub history, so nothing can be lost.

FileWhat it controlsYours?
site/art/Images for the site. It already holds og.png, the link preview. Put your mentor art here too, then add one line per image in content.js under art, like m2: "art/m2.webp".You
site/styles.cssThe whole Concept A look: colors (top of file), fonts, folder, badge, ticket, seal, sheets, planner, faculty, rosters.You
site/app.cssNewer pieces: login button, application forms, office-hours booking, desk, mentor calendar, staff tables, demo bar.You
site/poster.webpThe event poster. The Katja badge art is cropped from it, so a new poster changes Mentor 01's crop too.You
site/content.jsAll the words that don't change: schedule, roles, resources, seminar slots, Discord links, the art list.You
site/index.html, desk.htmlPage structure, section order and the link preview tags.You
site/home.js, desk.js, ui.jsBuild most of the page markup: badges, forms, the booking card, the mentor calendar. Layout changes often happen here.You
site/api.jsLogin and data. Rarely needs design changes.You, rarely
supabase/schema.sqlDatabase and booking rules. Only for changes to what gets saved.You, rarely

Run it on your computer

  1. Open a terminal in the folder this page is in (the one that holds site).
  2. Run the command below (it needs Python), then open http://localhost:8766.
  3. Edit a CSS file, save, and refresh the browser.
py -m http.server 8766 --directory site

On a Mac, use python3 instead of py.

Decisions waiting on you

Display art: mains or theme skins?

The plan says the badge shows each mentor's main. Placeholders use the Academy and Season 9 theme skins for now. Pick one rule for all eight.

Team tag color

The staff ID spec asked for a green tag. Everything else is red, ink and kraft. Keep the green, or bring it into the red family?

Poster as hero?

The site and the link preview both rebuild the poster in the site's style. Do you want the actual poster art shown anywhere?

Mobile

Check the demo on your phone. The folder, ticket and badge stack in one column, and some rotations are reduced. Flag anything that feels off.
